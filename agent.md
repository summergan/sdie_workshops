# Agent Entry

This repository keeps the canonical Codex project instructions in
`AGENTS.md`.

For non-trivial changes:

1. Read `AGENTS.md`.
2. Load `.codex/skills/sdie-harness-loop/SKILL.md`.
3. Load `.codex/skills/sdie-harness-loop/references/sdie.md`.
4. Load the relevant repo reference, usually
   `.codex/skills/sdie-harness-loop/references/repo-map.md` or
   `.codex/skills/sdie-harness-loop/references/testing.md`.
5. Keep `tasks/spec.md`, `tasks/plan.md`, and `tasks/todo.md` current while
   moving through Specification, Design, Implementation, and Evaluation.
